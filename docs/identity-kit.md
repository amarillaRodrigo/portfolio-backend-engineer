# Identity Kit — Portfolio Style Guide

## Typography
| Use | Font | Weight | Size (desktop) | Size (mobile) |
|---|---|---|---|---|
| H1 (section title) | Space Grotesk | 600 | 40px / line-height 1.15 | 28px / 1.2 |
| H2 (subtitle) | Space Grotesk | 500 | 28px / 1.2 | 22px / 1.25 |
| Body | IBM Plex Sans | 400 | 18px / line-height 1.6 | 16px / 1.6 |
| Small labels / meta | IBM Plex Sans | 500 | 13px, letter-spacing 0.04em, uppercase | 12px |

## Colors
| Role | Hex | Use |
|---|---|---|
| Primary text | `#12140F` | All body text on light background |
| Background | `#F7F6F1` | Base page background |
| Primary (green) | `#1F3D2E` | Headers, highlighted block backgrounds, icons |
| Decorative accent | `#B8A369` | Borders, label backgrounds, thick underlines, icons — **never as text/link** |
| Functional accent (text/link) | `#8A6D2E` | Links, highlighted text, any gold that needs to be read |

Quick rule: **light gold decorates, dark gold is read.**

## Spacing
- Base unit: `8px`. Everything a multiple of 8 (8, 16, 24, 32, 48, 64, 96).
- Between paragraphs: `24px`.
- Between blocks within a section: `48px`.
- Between sections: `96px` (desktop) / `64px` (mobile).
- Content side padding: `24px` mobile, `64–96px` desktop, max text line width ~`680px`.

## Contrast rules (don't touch)
- Primary text on background: `#12140F` / `#F7F6F1` — contrast >11:1, always valid.
- Never use `#B8A369` for reading text, only `#8A6D2E`.
